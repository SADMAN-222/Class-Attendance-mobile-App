# 📱 Class Attendance App

An Android application to efficiently manage student attendance with cloud-based storage and role-based access (Faculty & Student). Built for schools, colleges, and coaching institutes to simplify and digitalize attendance tracking.

> 🚧 **Note:** This app is under active development — more features are coming soon!

---

## ✨ Features

- 👨‍🏫 **Faculty Login** (via SharedPreferences)
- 👨‍🎓 **Student Login** (via SharedPreferences)
- 📋 Add and manage students
- ✅ Take and save attendance
- ☁️ Store attendance data securely on the cloud
- 📊 View attendance percentage for each student
- 🔐 Role-based access (faculty can manage; students can only view)

---
